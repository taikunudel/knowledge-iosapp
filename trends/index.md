# Trends

Nutrition trend graphs, pinned-nutrient monitoring, and trends-view routing.

## Documents

* [Pinned Nutrients Monitor](pinned-nutrients.md) - Users can pin any nutrient so its today-running total shows on the Today page with units and an over/under indicator.
* [Trends Graphs — In-Place Expansion, Pinned-First, Custom Goals](trends-graphs.md) - Trends rows expand into a graph in place, pinned nutrients sort first and auto-expand, and per-nutrient custom goals are supported.
* [Trends Routing — Local-Only Until HealthKit Path Has Feature Parity](trends-routing.md) - Trends routing is hard-coded to the local view until the HealthKit path gains per-nutrient pinning and excluded-date filtering.
