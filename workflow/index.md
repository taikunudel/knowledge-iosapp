# Workflow

Durable process rules for the Nutritionist project — how to document requirements, run multi-step tasks, and keep git clean.

## Documents

* [Meta Rule: Document Every User Requirement Here](meta-rule.md) - Every user-stated requirement, preference, or rejection must be recorded in CLAUDE.md before moving on.
* [Workflow Preferences](workflow-preferences.md) - Finish before reporting, explicitly enumerate documentation changes, and verify builds by parsing BUILD SUCCEEDED / BUILD FAILED.
* [Git Hygiene](git-hygiene.md) - Paths that must stay git-ignored, and the rule to stage named files rather than git add .
