# Human Interface Guidelines — map + iOS 27 deltas

> **Canonical sources (always richer + more current than this page):**
> [Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) ·
> [What's new — Design](https://developer.apple.com/design/whats-new/).
> The HIG is **evergreen and frequently updated**, so this page is a deliberate MAP +
> changelog, NOT a copy. For the authoritative text of any topic, open the link.

## HIG structure (top level)
- **Design fundamentals:** Design principles · Designing for iOS · Designing for macOS (see *Getting started*).
- **Foundations:** Accessibility · App icons · Color · Layout · Materials · Typography.
- **Topics:** Getting started · Foundations · Patterns · Components · Inputs · Technologies.

## iOS 27 / 2026 deltas (from "What's new — Design", June 8 2026)
New tools: **Pass Designer**; **Icon Composer 2 beta** (layered Liquid Glass icons); **SF Symbols 8 beta**.

Updated / new HIG pages:
- **Design Principles** — reintroduced. (See [[principles-of-great-design]].)
- **App Icons** — refined for Liquid Glass.
- **Search Fields** — updated terminology; refined guidance for search-as-a-tab on iOS. **Searching** — terminology + best practices. (See [[design-search-experiences]].)
- **Sidebars** — updated icon colors; clarified the adaptable sidebar style.
- **Menus** — guidance for menu-item icons.
- **Scroll Views** — guidance for scroll-edge effects.
- **Tab Bars** — updated terminology + art.
- **Siri** — revised for Siri AI. **Snippets** — new page. **App Shortcuts** — adopting app schemas.
- **Generative AI** — result refinement, feedback during content generation, model-type selection. **Machine Learning** — minor clarity.
- **Apple Pay** / **Wallet** — latest appearance; Wallet updated for iOS 27 + Pass Designer.
- (March 24 2026: **Sheets** button placement; **Scroll Views** Look-to-Scroll on visionOS.)

- **Search Fields / Searching** back our new Library `.searchable` ([[design-search-experiences]]).
